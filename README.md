# Bakhita-website
It is a website project to check on using JavaScript,HTML and CSS.It is a clean, modern and responsive personal website showcassing web development projects, interactive components, and proffesional journey.
# Live Demo
https://github.com/bakhita579/Bakhita-portfolio
# Features List
* smooth-scrolling navigation - quick links that glide smoothly to specific sections of the page.
* Dynamic content rendering - uses JavaScript array and DOM manipulation to inject project cards and testimonials dynamically.
* Responsive design - built using CSS grid and flexbox to look great on both mobile and desktop screens.
* Interactive elements - hover effects, structured layout cards and direct links to the Github repositories.
